# 黑球视觉闭环控制

该模块在摄像头画面中检测黑色圆球，并通过 SO-101 的关节微步进减小目标中心与画面中心的偏差。真机控制前应先完成摄像头预览和方向映射检查。

## 图像检测

检测静态图像：

```powershell
..\.venv\Scripts\python.exe visual_closed_loop.py image 图片路径.png
```

## 摄像头预览

```powershell
..\.venv\Scripts\python.exe visual_closed_loop.py camera --camera 1 --rotate 180
```

当前真机默认使用 GENERAL WEBCAM `1`，并在检测前旋转 `180°`。如果以后改变摄像头安装方向，可使用：

```text
--rotate 90|180|270
--invert-x
--invert-y
```

预览模式显示检测圆框、画面中心、像素误差和控制方向，不连接机械臂。检测器会排除过大的深色圆形区域，并要求连续帧的圆心和半径一致；将目标分别放在画面四个方向，确认方向映射后再考虑真机闭环。若现场黑球尺寸不同，可用 `--max-ball-radius-fraction` 调整允许的最大半径比例。

双击 `运行视觉闭环.cmd` 会进入真机闭环；完成摄像头和六轴安全检查后，终端仍会要求输入大写 `MOVE`。

## 真机闭环

```powershell
..\.venv\Scripts\python.exe visual_closed_loop.py run --camera 1 --rotate 180 --headless --port COM5 --real
```

启动前需要：

1. 连续稳定检测到黑球；
2. 通过六轴型号、位置、EEPROM 限位和扭矩检查；
3. 在终端输入大写 `MOVE`。

控制器每次优先处理像素误差更大的轴：左右方向使用 ID1 底座微调，上下方向使用 ID4 腕部微调。关节目标按像素误差自适应为 8–24 个原始刻度；距离目标较远时使用较长的连续运动段，接近中心时自动缩小。ID4 走圆弧，因此允许末端在上下移动时同时发生前后位移；控制目标是让末端朝黑球靠近，而不是保持固定 X/Y 平面的严格直线运动。目标丢失、关节没有产生有效位移或连续两次移动导致总像素误差增大时，程序停止并关闭扭矩。

直接命令的默认限制为 40 步、累计 8 cm。双击启动器使用实测平滑配置：每段请求 2–10 mm、误差增益 24 mm，运动后等待 120 ms 并丢弃 2 帧旧画面，最多 8 段、累计 3 cm。累计距离按“请求位移和末端实测位移中的较大值”计数；每个动作前还会按关节目标预测位移，预计会超过剩余额度时不会下发该动作。可通过 `--max-moves` 和 `--max-total-cm` 调整。

该控制器根据二维图像误差选择动作，不单独测量目标深度，也不执行碰撞检测。ID4 圆弧会改变末端前后位置，真机运行时必须保留三维安全空间并准备切断电源。

## 测试

```powershell
..\.venv\Scripts\python.exe -B -m unittest -v test_visual_closed_loop.py
```

测试覆盖圆球检测、非圆和过大目标排除、图像旋转、坐标反转、同一目标稳定门槛、死区停止、ID1/ID4 微调规划和合成闭环收敛。
